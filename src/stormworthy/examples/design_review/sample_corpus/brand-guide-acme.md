# Acme brand guide (fictional)

Register: calm, precise, instrument-panel. The product's credibility claim is accuracy, so the
visual system must never over-assert.

## Contract

- **Accessibility-first**: all text meets WCAG 2.2 AA — 4.5:1 for body text, 3:1 for large text
  and UI components. This is a contract, not an aspiration.
- **Type scale (locked)**: 12 / 14 / 16 / 20 / 28 / 34 px. Nothing functional below 12 px; no
  off-scale sizes. One hero size per screen — adjacent sizes (18/17/16) reads as no hierarchy
  at all.
- **Accent teal** is reserved for **interactive elements on dark surfaces**. On the light canvas
  it drops below the contrast contract and must not be used as text.
- **Spacing**: 4 px grid; one card gap, one card inset, one section step.
- **One signature**: the hero metric with its sparkline. Everything else recedes.
